# 素材来源与取图

接口记录核对日期：2026-10-28。站点和接口可能变化，使用时以当前页面为准。可查看或下载不等于统一授权；记录明确声明和未知项，不编造授权结论。

## 默认固定路线

普通任务默认只自动访问两个来源：

1. [shufa5书法字典](https://www.shufa5.com/)：首选。按单字表单查询所选书体，优先取得背景简单的静态字例。作者是网站标注，多数字例没有原帖名称。
2. [书法空间9610](https://9610.com/zidian/)：仅补首选未取得或看图后退回的字。走正常查字列表及所选字例详情页，记录完整原帖说明；拓片和纸色仍需看图判断。

先读本地缓存，再按上述顺序；已取得候选的字不在第二站重复搜索。大鹏为精细需求的第三来源，默认快速取图不调用其内部接口。其原图链接在实测中出现过403，不应逐字不断刷新。

不把词典网镜像、书法图集、以观、馆藏或全网搜索列为普通任务的自动回退。它们的水印、登录条件、接口变化或裁字工作可能增加时间；只有明确需要进一步溯源或固定来源不能满足关键条件时再用。可访问不等于有商业授权。

## 一条命令批量取图

```text
python <SKILL_DIR>/scripts/lettering.py fetch --text "山水清音" --script 行书 --output <新的取图目录> --cache-dir <工作区内的缓存目录>
```

不依赖API key、现有字库或服务，只用Python标准库和Pillow。网络权限由宿主决定；网络被拦截时明确报告，不把它当作查无此字。不要另写站点解析或下载脚本。

- 默认90秒取图预算，单请求最长6秒，最多3路并发；同一站点连续两次网络失败后，本轮暂停该站点。到预算后不发新请求，在途请求可能稍后结束。
- 每个不同汉字只查询一次，每字默认2张候选（`--max-candidates 1`可进一步减少下载），最多3张；重复字保留各自位置，复用同一下载文件。
- 可用`--author 苏轼 --strict-author`保持指定书家硬条件；不带strict只作偏好。默认按整组书家覆盖度和所选书体排序，不擅自改字或改繁简。
- `--sources 9610`只补查被退回的字，使用新的取图目录；不要对整组再次查询。`--budget-seconds`可以调整预算，0表示仅使用缓存。
- 缓存默认位于取图目录上一级的`.calligraphy-cache`，查询有效期7天，包含按需取得的原字节、出处和SHA-256；复用前核验哈希。缓存不保存视觉通过状态，不等于已审核字库。可删除整个缓存后重取。

输出downloads/原件、pages/所读页面、candidates.json、fetch-report.json、候选拼图及selection.json模板。fetch-report记录耗时、网络请求、缓存命中、各字尝试及拼图编号对应的文字／作者／文件。所有character_verified初始为false，Agent查看候选拼图后才能选字和填写说明；首张只是候选，不是已确认的最佳字形。

空结果、网络失败、下载失败和预算不足分开记录。只根据成功读取的页面判断无候选；字例尺寸过小或不是可处理静态图时跳过，不自动清水印、补笔或称为高清。精细核字、裁框与PNG/SVG处理见任务格式和矢量化说明。

## 精细需求的额外来源

- [大鹏书法字典](https://zidian.dapengshufa.com/)：按文字、书家、书体和碑帖查找，支持原帖定位。可从当前页面取得字形ID、版本、原帖坐标和图片地址。
- [书法字典](https://www.shufazidian.com/)：从可见查询控件检索，核对作者及原帖。没有稳定公开接口时使用正常网页，不伪造令牌。
- [以观](https://app.ygsf.com/)：先确认网页版是否可用及访问条件；仅凭宣传数量不算取得素材。

大鹏前端内部检索接口的请求记录：

```text
POST /api/v1/glyphs/search
```

```json
{"text":"山水","matching":"traditional_simplified","filters":{"script_tags":[],"author_ids":[],"edition_ids":[]},"limit_per_position":3,"cursors":{}}
```

返回positions及各位置的input、total_count、items；字形包含character、author、book、script、edition_id、page、thumb_url、revision、box、size。来源页格式为`/work/<edition_id>/<page>`。ID从真实页面或响应取得，不猜测。

原图接口记录为`GET /api/v1/glyphs/<glyph_id>/original?revision=<revision>`，可返回status、url、dimensions和expires_in。只有当前页面仍使用该接口时才按其实际形状请求；它不是承诺稳定的公开API，失败后转网页或换源，不扫描接口。

临时图像地址过期时回来源页刷新，以expires_in等实际字段判断有效期，不写死签名地址。原图可能与缩略图分辨率相同；扩展名与实际编码也可能不同，以解码结果为准。下载原件后裁去字区外页脚，不能裁掉笔锋。

## 原帖与馆藏

- [书法空间9610](https://www.9610.com/)：可按书家浏览完整作品，读取页面实际大图链接；不沿文件编号猜图或批量下载。整帖需要看图定位和核字，作为超出单字快速路线的精细处理。
- [国立故宫数字典藏](https://digitalarchive.npm.gov.tw/)：核对作品记录、馆藏号、释文和页码，再从作品页取得IIIF manifest，按其实际图像资源裁字。同名作品可能有多个版本，不能仅凭标题匹配。
- [哈佛燕京图书馆特藏](https://library.harvard.edu/libraries/harvard-yenching-library/special-collections)：沿馆方目录确认拓片来源；转载合集编号或文件名不能替代馆藏号。

## 选图与异常处理

优先同一书家或同一帖，选完整、清楚、背景简单、尺寸接近的原字。搜索缩略图只作为线索，打开来源页并尽量取得实际大图。网站标注归属仅支持source-labeled，不等于独立鉴定。

快速路线首轮默认2张、最多3张候选；看图退回后只补查一次，不重新比较全站。精细需求最多检查3个有效来源，仍无结果时停止并记录。将网络错误、过期、登录／付费限制与真正无候选区分；不绕过安全警告。需要账号的来源先换可用资源，无法满足硬条件时明确报告。

邻字残边可调整裁框；红印、水印覆盖笔画、原图残缺或纸色与笔画无法分离时换图或留缺字。不得擦除压在笔画上的水印、捏造笔锋或用生成图冒充原帖。
